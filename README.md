# Java Calculator

A simple calculator web application built with Java, HTML, CSS, and JavaScript.

## Features
- Addition, subtraction, multiplication, and division
- Modulo operation
- Clear and delete buttons
- Keyboard support
- Responsive layout
- Java HTTP server backend
- Expression parsing in Java (no extra libraries required)

## Technologies
- Java
- HTML5
- CSS3
- JavaScript

## Requirements
- JDK 11 or newer
- VS Code or any code editor

## Run locally

1. Open this project folder in VS Code.
2. Open the terminal in this folder.
3. Compile the Java file:

   ```bash
   javac Calculator.java
   ```

4. Start the server:

   ```bash
   java Calculator
   ```

5. Open this address in your browser:

   `http://localhost:8080`

Press `Ctrl+C` in the terminal to stop the server.
